文本输入检查发现：`%s = #eval table_size()` 经当前 parser 得到 3002（unknown opcode）。
`is_eval` 数据字段与 fold 代码存在，文本输入、打印往返与 Meta 接入仍须分别验证。

| 目标 | 所需证据 |
| --- | --- |
| Meta 可替换 | 两个独立实现通过同一公开接口和驱动，诊断读取不依赖其中一个的内部布局 |
| 编译期计算接入 Meta | 从源输入到 eval 折叠，再到 Meta 消费结果的端到端正例与拒例 |
| Lain 编写的 Meta | 必需语言子集、可执行编译入口与实际运行结果 |

这些目标尚需上述专项验收；重复构建一致只证明产物的确定性。
