## 下一步

### 1. 完成暂存区分配迁移

检查 `scope.l1` 的启动认领公式、表达式结果 sheet 和参数组暂存位置。
启动表与临时块使用明确的分配顺序，嵌套临时块遵循 mark/release；容量不足报 17。
布局变更同步更新 `parse.l1`、`registry.l1`、`modules.l1`、`funcs.l1`、`meta.l1` 和驱动诊断读取。
具体偏移只在 `scope.l1` 维护，本文不复制一份容易失效的表。

验收：现有 Meta 用例全通过；前后快照逐条比较；新增深层嵌套、长模块路径、空间恰满与不足的用例。
失败时不覆盖其他表，成功时实参与结果均正确，驱动报告峰值。

### 2. 补齐语言组合验收

为 if、字段读取、局部绑定、调用实参和 return 位置建立组合用例。
每个通过项断言结果和必要的产物文本；不支持的形式记录具体诊断，避免把“验证器没报错”当正确。
尤其保留有符号/无符号比较、递归后算子恢复、三项运算链与多层嵌套实参的回归。

### 3. 检查语法错误诊断

检查分隔符不配对等输入的诊断。先复现缺口，再补错误路径与稳定诊断码。
分别测试未闭合分组、错误关闭符、字符串结束和输入耗尽；失败不得继续发射可执行产物。
