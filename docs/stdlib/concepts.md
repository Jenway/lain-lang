## 函数的两类输入

函数签名把运行时输入和编译期输入分开表示：

```lain
let max = std::func(a: T, b: T)
    ?{
        T: Type,
        ord: Ord(T),
    }
    -> T
{
    return ord.less(a, b) ? b : a;
};
```

`(a: T, b: T)` 描述运行时输入；`?{ T: Type, ord: Ord(T) }` 描述具体化时需要的编译期输入及其约束；`-> T` 描述返回类型。若函数还声明运行时 effect，签名中使用独立的 `!{ ... }` 部分。`?{ ... }` 与 `!{ ... }` 的求解和执行阶段不同，不应混为同一组参数。

`T` 是一个类型值，`Type` 约束它必须是可用的类型；`ord` 是满足 `Ord(T)` 要求的编译期值。这里没有专属的“泛型类型参数”类别。其他编译期值可以按同一机制传入，例如：

```lain
?{
    T: Type,
    N: usize,
    cmp: Comparator(T),
    layout: LayoutPolicy(T),
}
```

`N` 可以影响数组长度，`cmp` 可以影响选用的操作，`layout` 可以影响具体数据布局。它们能否在运行时产物中留下数据或调用，由 Meta 的具体化与 lowering 结果决定；声明本身不规定统一的运行时表示。

## 类型与类型工厂

类型是可传递、组合、计算并由 Meta 函数生成的编译期值。类型工厂接收普通编译期值并返回类型值，例如概念上的 `Vec(i32)` 或 `Result(i32, Error)`。Meta 根据被调用对象和上下文解释调用：同样的括号形式也可能是普通函数调用、类型构造或其他 Meta 操作。类型身份、相等性和工厂结果的缓存规则仍需单独定义。
