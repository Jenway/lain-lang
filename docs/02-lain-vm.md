# Lain-VM

> [!QUOTE]
> Lain-IR 能够解释执行（嗨，多稀奇啊）。
> 
> 由 Lain-VM 来在编译期执行 LAINIR。

## 核心实体与分工

Lain-VM 采用能力微内核架构，将物理执行环境解耦为相互正交的核心实体：

| 实体 | 职责 | 明确不管 |
| :--- | :--- | :--- |
| **VSpace** | 物理内存的申请与释放；区段划分与映射；当前可访问范围；READ / WRITE / CALL 权限；稳定区段句柄。 | 执行流状态、当前指令计数器、栈水位。 |
| **TCB** | 线程控制块。保存指令位置、调用栈帧（frame/slot）、栈水位回退点；持有 VSpace、CSpace 与 Quota 的引用；记录执行终态。 | 不申请、不释放、不拥有物理存储；不直接扣减配额。 |
| **CSpace** | 提供执行流可调用的宿主服务能力表。 | 内存权限判定、业务逻辑计算。 |
| **Endpoint** | 执行流间的通信会合点（IPC Rendezvous）。负责 TCB 间的控制权转移、同步挂起与消息交接。 | 消息的高级语义解释、调度策略。 |
| **Trap** | 记录执行失败的分类、状态码与过程/指令位置。 | 错误恢复逻辑、用户诊断展示。 |

TCB 引用 VSpace，多个 TCB 可共享同一地址空间。TCB 对 LAINIR 保持不透明，不作为程序可读写的控制结构。

上表之外还有两个**机制与产物**：

| 机制 | 产物 | 明确不管 |
| :--- | :--- | :--- |
| **Image** | 装载后的模块：名字换成槽、符号已解析、数据地址烤进映像；只读 / 读写 / 代码三段。 | canonical 文本与名字解析（那是 artifact 的事）。 |
| **Engine** | 取指 -> 查表 -> 执行一步（CU + ALU）。无状态：可变状态都在 TCB 里。 | 分配、调度、预算、阻塞处置。 |

代码侧一一对应：Trap 的码表在 lain/vm/trap.h，端点在 lain/vm/endpoint.h，
地址空间在 lain/vm/space.h，TCB 在 lain/vm/tcb.h，
映像与引擎都在 lain/vm/engine.h（映像的结构是引擎私有的）。

## 物理内存模型（VSpace）

### 区域记录：容量与可访问窗口
VSpace 内的物理存储区段严格区分底层容量与当前可访问前缀：

```text
[base, base + accessible)   ──> 当前合法访问前缀（访问越界由此判定）
[base, base + capacity)     ──> 底层物理存储占用（重叠检查与容量上限）
```

- 存储分为 **OWNED**（VSpace 分配并向 Quota 计账）与 **EXTERNAL**（外部借入映射，不向 Quota 扣费）。
- 窗口缩放仅调整 `accessible`，区段句柄全程稳定。窗口收回后，旧范围的访问立即失效。

### 存储接口契约
- **alloc**：Quota 原子预扣 $\to$ 底层分配 $\to$ 内存清零 $\to$ 登记 OWNED 区段。任一步骤失败全部回滚。
- **free**：撤销区段 $\to$ 释放底层存储 $\to$ 按实际扣费账户全额归还 Quota。存在活借用、重复释放或跨空间操作一律拒绝。
- **map_external**：登记外部传入的内存切片并赋予访问权限；不分配底座存储，不扣减 Quota。
- **unmap_external**：仅撤销外部映射；不释放底层指针，不操作 Quota。
- **borrow / end_borrow**：增减活跃持有人计数。活借用未清零前禁止释放该区段。

### 裸地址（#addr）语义
- `#addr` 是**无类型裸物理地址**：仅表示机器字长数值，不携带对象身份、世代（generation）或目标类型。
- `#addr` 的有效性完全由当前 VSpace 的授权范围与权限位判定。过程结束且区段撤销后，旧地址访问失效；同一数值地址若被重新分配授权，旧裸地址与新裸地址物理上不可区分。
- 高层引用的对象级时间安全（如借用检查、世代安全）属于 Meta 层的抽象规则，由 Meta 降解为具体物理值，不改变底层 `#addr` 的规范。
- `#int2ptr` 与 `#ptr2int` 仅执行位模式转换，`#int2ptr` 不授予任何内存访问权限。

## 执行流与控制转移（TCB 与 Endpoint）

### 栈租约协议
TCB 不直接拥有栈内存，其执行栈通过 **栈租约（Stack Lease）** 借用自 VSpace：

1. **供给**：调用方在 VSpace 内预留整块栈存储（初始 `accessible = 0`）；
2. **借用**：创建 TCB 时传入栈租约，区段 `borrow_count` 递增；一份栈租约在同一时刻只允许借给一条执行流；
3. **执行**：执行期间 TCB 根据指令调用推进或回退 `accessible`（栈水位）；
4. **归还**：TCB 销毁或根过程退出时，水位归零，结束借用（`borrow_count--`）；TCB 自身不释放底层内存，不归还配额；
5. **销毁**：供给方显式释放区段，物理存储被回收，配额归还。

### alloca 的生命周期
- `#alloca` 的生命周期**绑定于当前过程激活（Procedure Activation）**。
- 进入或离开结构化控制流（`#if`、`#loop`、`#switch`）不改变栈生命周期；只有过程返回、Trap、取消或 TCB 销毁时才收回水位。
- `#alloca` 的计数为独立的无符号常量，表示元素个数；物理分配字节数恒为 `count × 元素类型字节数`。
- 循环内部执行 `#alloca` 会持续推进当前激活帧的水位；超出栈租约容量时拒绝执行。

### Endpoint 机制
Endpoint 是 VM 内部多执行流同步与控制转移的原语：
- **同步会合**：TCB 向 Endpoint 发送或请求接收时，若对端未就绪，当前 TCB 进入挂起状态；两端就绪时完成控制权交接或数据复制。
- **低层抽象中立**：VM 不定义协程、通道（Channel）或代数效应（Effect Handler）的高级语义。所有异步挂起、协作式调度与控制流转移，统一由 Meta 编译降解为 TCB 在 Endpoint 上的等待与唤醒。

## 能力空间（CSpace）：注册与冻结模型

CSpace 负责管理执行流可调用的宿主服务（外部符号与回调函数）。

### 核心机制
- **项的构成**：外部符号名（`link_name`） + 类型 + C 回调函数指针 + **可信上下文指针（`context`）**。
- **注册与冻结**：
  - 宿主在初始化阶段通过可信路径登记能力，绑定内部 `context`；
  - 登记完成后执行 **`freeze`（冻结）**。冻结后禁止新增、扩容或篡改任何绑定，保证表项地址全程稳定；
  - TCB 只能挂载已冻结的能力表。
- **隐式上下文注入**：
  宿主调用签名固定为 `fn(context, raw_args, arg_count, result_out)`。
  - `context` 由 VM 在分派时根据表项自动注入；
  - `context` 不进入 `raw_args`，不占用 LAINIR 业务参数槽，不能被 LAINIR 代码读取或篡改；
  - LAINIR 参数仅承载业务数据。
- **生命周期**：能力表与绑定的宿主上下文必须活到所有引用它们的 TCB 销毁之后。释放顺序严格为：TCB $\to$ 能力表 $\to$ 宿主。

## 配额机制（Quota）

配额是 VM 对底层存储资源承诺的全局统一标尺，以**实际承诺字节**为单位。

- **账户归属**：配额账户由最外层执行上下文创建，嵌套执行共享同一个账户。
- **扣费点**：
  - 发生在 VSpace 实际分配物理存储的时刻（如栈租约整块预留、宿主暂存区与输出缓冲扩容）；
  - 栈预留时整块扣费一次，执行期间内部 `#alloca` 的水位推进不重复扣费，水位回退也不归还整块额度；
  - 仅在物理存储被真正释放时归还额度。
- **原子性**：配额预扣为原子操作。余额不足或算术溢出时立即拒绝，账目不发生改变；预扣成功若遭遇底层系统分配失败，必须完全回滚。

## 执行终态与后端约束

### 执行与 Trap
执行请求输入已验证的 LAINIR 模块、入口过程、实参、地址授权、能力表与预算。
- **确定性失败**：非法访存、配额耗尽、算术溢出等均转换为确定性的 Trap，转由上层诊断。宿主异常崩溃不构成合法执行终态。
- **切片与预算**：调度切片耗尽仅代表当前调度周期结束，不代表共享配额耗尽。

### 解释器与编译后端一致性
解释执行器与任何原生编译后端（如 C 后端）必须维持等价的系统契约：
- 目标代码必须对内存范围、栈生命周期与配额实施与 VM 等价的约束判定；
- 后端不得以“零开销”为由省略边界检查，保证同一程序在解释执行与编译执行下的行为与失败判定严格一致。
