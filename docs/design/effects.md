# Effect

Effect 表示一段程序可能请求的操作，例如读取文件、报告业务错误或挂起执行。
Meta 负责检查这些请求如何声明、传播和处理。宿主能力决定编译期执行实际可以调用哪些外部服务。

语言中声明某个 effect，不会自动获得对应宿主权限。驱动需要提供相应能力，执行环境再验证调用。
业务失败可以由语言定义的返回值或 effect 表达；物理执行中的越权和资源耗尽交给 VM 的失败协议。

Handler 是处理某类操作的程序。若支持恢复执行，需要定义恢复次数、被保存状态的寿命以及退出时的清理。
这些规则确定后，才可以选择转换为普通调用、显式 continuation 或由 VM 保存执行上下文。
不同实现的开销取决于实际控制流和目标平台，本文不预设零开销。

本文件保留设计方向，不规定尚未实现的 effect 语法或 handler ABI。
TCB、Endpoint 或切片执行的存在，不能单独证明完整 effect 系统已经可用。
当前语言范围见 [Meta v0](../spec/meta-v0.md)，执行边界见 [VM 契约](../spec/vm.md)。
